Method not allowed / other errors

To test 405, hit an allowed-methods-restricted location with a disallowed verb (e.g. DELETE tester above against a GET-only location). To test 415, use the raw curl commands below.

curl one-liners (for edge cases forms can't trigger)

# wrong content-type on /login -> expect 415
curl -i -X POST http://localhost:PORT/login -H "Content-Type: application/json" -d '{}'

# wrong content-type on /upload -> expect 415
curl -i -X POST http://localhost:PORT/upload -H "Content-Type: text/plain" -d 'x'

# body too large -> expect 413 (adjust size vs client_max_size_body)
curl -i -X POST http://localhost:PORT/login --data-binary @bigfile.txt

# DELETE via curl
curl -i -X DELETE http://localhost:PORT/uploads/somefile.txt

# malformed percent-encoding -> expect 400
curl -i "http://localhost:PORT/%zz"
